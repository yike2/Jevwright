Jevwright

Browser tests your agent can write in plain steps.

Each step is one action or one assertion. Jev finds the element from a screenshot or the page’s DOM, so a layout change doesn’t break the test.

name: "User login" steps: - open: "https://demo-shop.jevwright.dev/login" - input: target: "Password field" value: "{{DEMO_PASSWORD}}" # never sent to Jev - click: "Sign in button" - assert: "The page greets the user by name"

Prototype: any email and an 8+ character password work. Nothing is sent to a server.
