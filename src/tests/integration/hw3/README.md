# HW3 Integration Fixtures & Demo App (`src/tests/integration/hw3/`)

This directory contains the three-page demo HTML application, the Playwright fixture extraction script, the generated screenshot/snapshot/ground-truth fixtures, the `BrowserDriver` stand-in, and the real-Jev evaluation runner.

## Directory Structure

- `pages/` — Demo HTML pages rendered at a `1024×768` CSS viewport (`deviceScaleFactor: 1`):
  - `login.html`: Sign-in form with email/password inputs, "Show password" button, "Remember me" checkbox, "Send a weekly summary" `role="switch"` button (`aria-checked="false"`), "Sign in" button, disabled "Sign in with SSO" button, "Forgot password?" link, and a non-interactive maintenance alert banner.
  - `tasks.html`: Task backlog page with "+ New Task" button, searchbox input, filter buttons, three task rows with repeated `"Delete task"` buttons, and a clickable release card containing a nested `"Archive Release"` button (testing smallest-area geometry matching).
  - `modal.html`: Workspace settings page with background inputs/buttons covered by a modal backdrop (`hittable: false`) and an active "Delete Workspace" confirmation dialog (`hittable: true`).
- `fixtures/<page>/` — Committed fixtures generated by Playwright:
  - `screenshot.png`: Viewport screenshot (`1024×768` PNG).
  - `snapshot.json`: Interactive element snapshot (`PageSnapshot`) with `id`, `tag`, `role`, `name`, `text`, `attrs`, `bbox`, `hittable`, and `texts`.
  - `targets.json`: Ground-truth targets (`id`, `target`, `action`, `present`, `elementId`, `bbox`, `selector`).
- `generate-fixtures.ts` — One-off Playwright script that opens each HTML page in headless Chromium and generates `fixtures/<page>/*`.
- `fixture-driver.ts` — `BrowserDriver` stand-in (`createFixtureBrowserDriver`) that serves the saved fixture files from disk so tests never need a browser.
- `eval-jev.ts` — Runs the Locator against every fixture target using the real `typesafe/jev-1.14` model on OpenRouter and prints per-method accuracy.

## Commands

Regenerate fixtures with Playwright:

```bash
pnpm fixtures:generate
```

Run unit and integration tests (offline, using the fixture `BrowserDriver` stand-in):

```bash
pnpm test
```

Run the real-Jev evaluation across all fixture targets (reads `OPENROUTER_API_KEY` from `.env`):

```bash
pnpm eval:jev
```
